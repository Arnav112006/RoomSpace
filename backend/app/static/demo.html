RoomSpace

AI-assisted room layout planning — live backend demo

LIVE

1. Create a room

Calls POST /api/rooms and persists it server-side.

LIVE

2. Upload a room photo — object detection

Calls POST /api/rooms/{id}/photo. Runs local YOLOv8 (no API key, no network call) to detect existing furniture in the photo and attaches the results to the room.

LIVE

3. Constraint Engine + SVG renderer

Calls POST /api/rooms/{id}/validate-layout. The Constraint Engine checks room boundaries, furniture overlap, and walkway clearance; the renderer draws the result — red for anything that fails.
